## 概念の整理（記事の核）

- 論理的思考 = 道筋を整理・整頓し実現化する技術。バグのない設計。**品質ではない**
- 批判的思考 = 品質・UX・クリエイティブ。ディレクタースキル。PdMが担ってきた領域
- 論理だけだと「良くも、悪くもないもの」になる。批判とループさせて引き直す
- セルフレビューでプレイヤー → マネージャー視点へ。「そもそもなんで作ってたんだっけ？」に自分で答えられるまで出さない
- エージェント時代の落とし穴: 出力量増 → タスク分割で見られる量に。レビュー省略の正体は「理解負債」（リポジトリを知ることが最速のレビュー）
- コスパ意識が逆に効率を下げる逆説。エージェントのメモリ・コンパクトと人間の「学ぶ→休む→復習」の相似
