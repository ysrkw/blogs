# スキル

このリポジトリのローカルスキル（`.claude/skills/`）の索引。何のためにいつ使うかだけ示す。挙動の実体は各 SKILL.md にある。

## ワークフロー

記事を公開まで運ぶ流れ。流れと段階の詳細は [workflow.md](./workflow.md) を参照。

| スキル       | 段階                | 用途                                                                                       | 発動語         |
| ------------ | ------------------- | ------------------------------------------------------------------------------------------ | -------------- |
| blog-ideate  | 1                   | コンセプトを対話で発掘し `works/{slug}/idea.md` に保存                                     | ネタ出し       |
| blog-outline | 2                   | 構成（タイトル候補・リード方針・H2/H3）を組む                                              | 構成を作る     |
| blog-writing | 3                   | 本文をセクション単位で書き起こす                                                           | 下書き         |
| blog-review  | 3〜4 の間（ループ） | 全体を通し読みし、機械チェック・人判断チェックを含めて推敲する。満足するまで何度でも呼べる | 通し読み・推敲 |
| blog-publish | 4                   | frontmatter を確定し `articles/` へ公開形で移す                                            | 公開準備       |

## 補助

ワークフローの流れとは独立して、記事の記録用途で使う。

| スキル   | 用途                                         | 発動語     |
| -------- | -------------------------------------------- | ---------- |
| book-log | 読んだ本を `docs/books/{slug}.md` に記録する | 本を読んだ |

## システム

記事のスラグに紐づかず、`blog-*` の命名規則にも属さない。セッション単位で自動発動する。

| スキル        | 用途                                                                  | 発動語              |
| ------------- | --------------------------------------------------------------------- | ------------------- |
| retrospective | セッションを振り返り、書き手の癖・進め方・改善案を `docs/` に蓄積する | 振り返り／Stop hook |

## 外部スキル

- humanizer: AI 臭い文章パターンを検出する。[blader/humanizer](https://github.com/blader/humanizer) を `~/.claude/skills/` に導入して使う（本リポジトリ外）。blog-writing / blog-review から観点を借りる。未導入ならそれらの humanizer 参照箇所は手動チェックで代替する

humanizer / textlint は丸ごと当てない。運用原則は [writing-policy.md](./writing-policy.md)「AI の執筆姿勢」を参照。
