# ビジョナリー・カンパニー2 飛躍の法則 / ジム・コリンズ（山岡洋一 訳）

- 概要: 「良い（good）」企業から「偉大な（great）」企業へ飛躍した 11 社を、株価実績を基準に選び競合と比較分析した本。軸になるのは第 5 水準のリーダーシップと、「誰をバスに乗せるか」を戦略に先立たせる人材論。さらに厳しい現実を直視する「ストックデールの逆説」、自社が世界一になれる領域を見極める「針鼠の概念」、規律ある文化と「弾み車（フライホイール）」などの法則を導く。第 5 水準のリーダーは、個人としての謙虚さと職業人としての強い意志を併せ持つとされる。
- 使いどころ: 企業を成長させるという時に経営側はこういう考え方を持っているということ。特に偉大な人は、特別な天才ではなく、ぶれない目的と規律ある意思決定を積み重ねた普通の人である、という点を指摘する時に。
