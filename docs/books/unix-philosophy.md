# UNIXという考え方 その設計思想と哲学 / マイク・ガンカーズ（芳尾桂 訳）

- 概要: 原題 The UNIX Philosophy。UNIX の設計思想を 9 つの定理として整理したエッセイ。代表的な定理は「Small is Beautiful（小さいものは美しい）」「1つのプログラムには1つのことをうまくやらせる」「できるだけ早く試作する」など。小さく単機能な道具を組み合わせる思想を説く
- 使いどころ: 小さなプログラムを組み合わせて柔軟性を手に入れる、という学びを引きたい。現代のプロダクト開発にも受け継がれている概念で、エージェントがシェルをうまく使いこなせるのもこの哲学のおかげ。我々の作る機能もこれを参考にする余地がある
