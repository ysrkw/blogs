# エンジニアリングが好きな私たちのためのエンジニアリングマネジャー入門 / サラ・ドラスナー（岩瀬義昌 訳）

- 概要: 原題 Engineering Management for the Rest of Us。エンジニアからマネジャーになる人へ向けた実務寄りの入門書。著者サラ・ドラスナーは Web フロントエンド界隈で知られる技術者であり、自身の経験をもとに書いている。信頼関係の構築を土台に置き、1on1、フィードバックの伝え方、心理的な安全性、会議の運営、採用やチームづくりといったマネジャーの日々の仕事を扱う。「私たち（the rest of us）」というタイトルどおり、特別なマネジメント素養を前提にしない語り口が特徴。
