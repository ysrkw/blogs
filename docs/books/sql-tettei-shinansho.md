# 達人に学ぶSQL徹底指南書 第2版 初級者で終わりたくないあなたへ / ミック

- 概要: SQL の初級者から中級者へのステップアップを狙う本。CASE 式・ウィンドウ関数・自己結合・相関サブクエリといった「考え方」を、手続き型ではなく集合指向で書くための技法として解説する。後半では SQL の歴史的背景やリレーショナルモデルの理論にも踏み込む。第 2 版ではウィンドウ関数の解説などが追補された。
- 使いどころ: SQL のパフォーマンスや設計の話を出したときにアドバイスとして出したい
