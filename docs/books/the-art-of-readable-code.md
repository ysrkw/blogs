# リーダブルコード ―より良いコードを書くためのシンプルで実践的なテクニック / Dustin Boswell・Trevor Foucher（角征典 訳）

- 概要: コードの読みやすさを最優先に置き、他人が最短時間で理解できるコードを良いコードとする実践書。命名・コメント・制御フロー・式の分割など表層の改善から、変数のスコープ短縮やコードの再構成、テストの読みやすさまでを具体例で示す。理論より現場で即使えるテクニックに振った構成で、日本語版には須藤功平氏による解説を収録。
- 使いどころ: 良いコードを言語化する時の参考文献として使いたい。
