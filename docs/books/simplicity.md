# シンプリシティ / Dave Thomas（島田浩二 訳）

- 概要（要確認）: 『達人プログラマー』の共著者 Dave Thomas が、ソフトウェア開発の不要な複雑さを見極めて減らす方法を書いた一冊。自分たちで複雑さを増やしていないかを問い直し、開発プロセス・コード・働き方をシンプルにするアプローチを示す。やることとやり方、環境、やり取り、コードの4つの側面から、すぐ始められるプラクティスを紹介する。
- 使いどころ: 弁証法的な思考という話が面白かった。「対立する両方の意見の意味に真実があるのを考え、それらを組み合わせて、どちらよりも優れた第3の案を作ること。」これらを後々記事へ込めるようにしたい。
