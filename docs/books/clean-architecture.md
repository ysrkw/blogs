# Clean Architecture 達人に学ぶソフトウェアの構造と設計 / Robert C. Martin（角征典・髙木正弘 訳）

- 概要: アーキテクチャの目的を「ソフトウェアを柔らかく保ち、変更コストを下げること」と定義し、SOLID 原則・コンポーネント原則・境界（バウンダリ）の引き方を体系化した設計書。方針（ビジネスルール）と詳細（DB・UI・フレームワーク）を分離し、依存方向を内側へ向ける「クリーンアーキテクチャ」の同心円モデルを核に据える。
- 使いどころ: アーキテクチャのバイブルとして思考を巡らせる時に、過去にクリーンアーキテクチャという考えが生まれていたことを解説したい。AI とクリーンアーキテクチャとの関係は良いのかを考える時にも利用したい。
