# Understanding is the new bottleneck / Geoffrey Litt

- 種別: web
- 要点: AI エージェントがコードを量産する状況では、人間の理解は検証のためだけでなく「開発へ参加するため」にも要る、という主張。そこがボトルネックになるとしている。理解があるからこそ、システムを次にどう進化させるかを創造的に考えられるという立場を取る。理解を進める技法として、差分を解説するドキュメント生成、記事に埋め込んだ間隔反復クイズ、システムの挙動を対話的に触れるマイクロワールド、チームで共有メンタルモデルを作る共有スペースを挙げている。AI Engineer カンファレンス（2026年7月）での講演を書き下ろした記事で、要点は本文とスライドで確認した範囲。
- 使いどころ: 理解負債という問題意識が自分だけのものではないことを示す参照先。理解を楽しく進める技法の紹介としても引く
