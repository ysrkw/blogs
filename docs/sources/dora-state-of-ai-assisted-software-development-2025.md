# State of AI-assisted Software Development 2025 / Google Cloud (DORA)

- 種別: web
- 要点: AI の主な役割は増幅器であり、組織がすでに持っている強みと弱みの両方を拡大するという主張が中心。強いチームはさらに速くなり、弱いチームは既存の問題が深刻化する。AI 採用はソフトウェア配信のスループットと製品パフォーマンスに正の関連がある一方、配信の安定性には負の関連があり、変更量の増加が既存システムの弱さを露呈させる構造を指摘している。約5,000名の技術専門家への調査と100時間超のインタビューにもとづく。要点はレポート紹介ページと Google Cloud の発表記事で確認した範囲であり、本文全体は未確認。
- 使いどころ: 「LLM は増幅器」という見方の根拠。組織レベルの知見なので、個人への適用は自分の見立てとして書き分ける
