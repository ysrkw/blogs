# sources

記事で参照する動画・Web記事・論文の索引。資料ごとの記録は `sources/{slug}.md` に置く。書籍は [books.md](./books.md) で管理する。

## 運用ルール

- 元資料のURL、タイトル、著者・発信者、掲載元、公開日を公式の掲載元で確認する
- 要点には資料の内容、使いどころには記事で参照する本人の意図を書く
- 全文を確認できない資料は、確認できた範囲を明記する
- 記事で使ったら「記事で引いた対応」と「登場記事」を更新する
