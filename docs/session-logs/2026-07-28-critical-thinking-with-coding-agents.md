## 言い換えた／書き直した表現

- 「このレールの引き直し」→「この線路の引き直し」。記事全体が「線路」で通っており、比喩の入口がぼやけるため
- 章の見出しを、たいていシンプルという形から「少ない手数で多くを解く」へ変更した。章の中身（KISS・実装しない選択・統合と分離）を広く回収できる形にするため
- 「レビューの総量は増える。省かせるのは理解負債」→「理解負債がレビューを省かせる」。見出しの句読点を排除する方針が決まったため
- 「この言語化をセルフでできています」という言い回しに本人が違和感を示したため、「相手に伝えるための言語化能力が高いと感じます」へ書き換えた。あわせて全称の断定を程度表現へ戻した
- 入力の説明を「渡せるのは、テキストか画像です」へ修正した。4段落後のスクリーンショットの記述が反例として同居していたため
- 「効きます」を「効果があります」へ置き換えた。「効く」系の述語は AI が書いた文に見えやすいため
- 「良いデザインは1つで2つのことを解決したりします」に一次体験を追加。重要なロジックを1クラスに集約して重複が消えた話。AI が用意したエラーメッセージの例は「1箇所に2つ載せる」に読めて弱かった
