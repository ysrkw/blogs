# notes

`/blog-reflect` がセッション終わりに書き出す「自己改善のための長期メモ」。
ナレッジは記事そのものではなく、**書き手の癖と進め方を未来の自分（と AI）に渡すための引き継ぎノート**。実ファイルは `notes/` 配下にある。読書記録は [books.md](./books.md)、確定した執筆スタイルは [writing-style.md](./writing-style.md) に分離した。ここには日付つきの生の気づき・進め方・提案ログだけを残す。

## ファイル

| パス                                    | 内容                                                                       |
| --------------------------------------- | -------------------------------------------------------------------------- |
| `notes/process-notes.md`                | ideate → outline → draft → polish の中で効いたやり方／詰まったパターン     |
| `notes/skill-improvements.md`           | 既存スキルへの改善提案ログ。`status: proposed / applied / rejected` で管理 |
| `notes/sessions/{YYYY-MM-DD}-{slug}.md` | セッション単位の生メモ。集約後も削除しない（経緯を辿るための一次資料）     |

## 更新ルール

- 重複する箇条書きを増やさない。同じ気づきは既存項目の追記で対応する
- 「断定 → 反例 → 修正」の流れがあれば履歴を残す（消して上書きしない）
- AI 風の総括をしない。**ユーザー本人の言葉**をそのまま引用する
