# エクストリームプログラミング / Kent Beck・Cynthia Andres（角 征典 訳）

- 概要: アジャイル開発の源流のひとつ XP を、価値・原則・プラクティスの 3 層で体系化した一冊。コミュニケーション・シンプリシティ・フィードバック・勇気・尊重という 5 つの価値を土台に置く。その上でペアプログラミング・テスト駆動開発・継続的インテグレーション・計画ゲームなどの実践を提示する。変化を抱擁する（Embrace Change）という姿勢で、変更コストを下げ続ける開発スタイルを描く。第 2 版の新訳。
- 使いどころ: プロダクト開発の基礎となる話や XP を振り返りつつ、コーディングエージェントの時代にどう取り込んでいくべきかを考えるときに使いたい。
