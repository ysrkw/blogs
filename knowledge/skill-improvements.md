# skill-improvements

既存スキル（blog-ideate / blog-outline / blog-draft / blog-polish / blog-reflect）への改善提案ログ。
`/blog-reflect` が追記する。**ユーザー判断で `applied` に変えてから** SKILL.md を編集する。

## ステータス

- `proposed`: AI が提案、未適用
- `applied`: SKILL.md に反映済み（日付と diff 概要を併記）
- `rejected`: 採用しない判断をした（理由を残す）

### 2026-05-26: blog-outline - 仮タイトル／仮方向を事前にヒアリングするステップを追加

- status: proposed
- 背景: organization-as-software の outline で、AI がタイトル案を 3 案 → 改稿 3 案 → 副題なし 3 案と出した後、本人が「もともとふわっと考えていたタイトルに近い形に寄せたかった」と自ら提案して着地した。ユーザーは事前に頭の中に仮タイトルを持っていたが、AI は聞いていなかったため往復が増えた
- 変更案: SKILL.md の「進め方 / 1. コンセプトの再確認」直後に以下のステップを挿入：
  - **1.5 仮タイトル・仮方向のヒアリング**: 「すでに頭の中にふわっとした仮タイトルや書きたい角度があれば教えてください。なければ次のステップで AI 案を出します」と一言確認する。あればそれを起点にし、無ければ従来通り 3 案提示
  - **補足（2026-05-26 critical-thinking-with-coding-agents セッションより）**: 仮タイトルがあっても探索をゼロにはしない。本人発言「会話することで思い出したこともあったので、そこまで無駄ではなかった」。仮タイトルを「起点」にしてバリエーション 2〜3 案を提示するイメージ
- 期待される効果: タイトル案の往復回数が減る。本人の潜在的な方向性を最初に拾えるので、AI 案も本人像に寄せやすくなる
