# skill-improvements

既存スキル（blog-ideate / blog-outline / blog-draft / blog-polish / blog-reflect）への改善提案ログ。
`/blog-reflect` が追記する。**ユーザー判断で `applied` に変えてから** SKILL.md を編集する。

## ステータス

- `proposed`: AI が提案、未適用
- `applied`: SKILL.md に反映済み（日付と diff 概要を併記）
- `rejected`: 採用しない判断をした（理由を残す）

### 2026-05-26: blog-ideate - 事前準備の有無を冒頭で確認するステップを追加

- status: proposed
- 背景: roi-thinking-for-engineers の ideate で、ユーザーは初発言の時点で「費用対効果 vs 投資対効果」「2 軸」「PdM 視点」まで整理された状態で出してきた。理由を聞いたら「技術勉強会で話していたのと、投資対効果について検索して調べていたから」。本人提案「事前にググっておくのは有効かも」
- 変更案: SKILL.md 「進め方 / 1. 挨拶と現在地確認」に質問を 1 つ追加：
  - 「このテーマについて、事前に勉強会・社内共有・検索などで触れていますか？」
  - YES なら整理確認（一文コンセプト・対比軸）をスキップ気味にして、一次体験の引き出しと独自角度の言語化に直行する
  - NO なら従来通りヒアリング 5〜7 問で掘る
- 期待される効果: 完成度の高い初発言で来たユーザーに同じ整理を再度させる無駄を減らす。一次体験・独自角度の深掘りに時間を割ける

### 2026-05-26: blog-reflect - Stop hook の `.reflect-state` 更新タイミングを前倒し

- status: proposed
- 背景: roi-thinking-for-engineers の ideate セッション終了時、Stop hook が振り返りを促した。AI が「今やる／後回し」を確認 → ユーザーが「今やる」と返答 → AI がヒアリング Q1 を投げる、までの間にユーザーが応答せず Stop を試みたところ、hook が同じ促しメッセージを再発火。さらに設計問題の議論中にも再発火し、合計 3 回ループした。原因は `.reflect-state` の更新が手順末尾にあるため、振り返りプロセス中の中間 Stop ですべて発火条件を満たしてしまうこと
- 変更案: SKILL.md 「進め方 / 1. セッション要約」の末尾に以下を追加：
  - **要約と確認メッセージを出した直後に `touch .claude/.reflect-state` を実行する**。後回し選択でも今やる選択でも、hook の義務は「促しを出した」時点で果たしたとみなす。書き出し完了時に再度 touch は不要（既に更新済み）
  - 「進め方 / 5. 締め」の touch 指示は削除または「既に 1 で更新済み」と明記
- 期待される効果: 振り返りプロセス中の中間 Stop で hook が再発火しなくなる。ユーザーがヒアリングに応答しない／設計議論に逸れた場合も hook ループが起きない
- 補足: 別案として hook 側で「促し済み」マーカーを持つ方法もあるが、SKILL.md だけの修正で済むこちらが現実的

### 2026-05-26: blog-outline - 仮タイトル／仮方向を事前にヒアリングするステップを追加

- status: proposed
- 背景: organization-as-software の outline で、AI がタイトル案を 3 案 → 改稿 3 案 → 副題なし 3 案と出した後、本人が「もともとふわっと考えていたタイトルに近い形に寄せたかった」と自ら提案して着地した。ユーザーは事前に頭の中に仮タイトルを持っていたが、AI は聞いていなかったため往復が増えた
- 変更案: SKILL.md の「進め方 / 1. コンセプトの再確認」直後に以下のステップを挿入：
  - **1.5 仮タイトル・仮方向のヒアリング**: 「すでに頭の中にふわっとした仮タイトルや書きたい角度があれば教えてください。なければ次のステップで AI 案を出します」と一言確認する。あればそれを起点にし、無ければ従来通り 3 案提示
  - **補足（2026-05-26 critical-thinking-with-coding-agents セッションより）**: 仮タイトルがあっても探索をゼロにはしない。本人発言「会話することで思い出したこともあったので、そこまで無駄ではなかった」。仮タイトルを「起点」にしてバリエーション 2〜3 案を提示するイメージ
- 期待される効果: タイトル案の往復回数が減る。本人の潜在的な方向性を最初に拾えるので、AI 案も本人像に寄せやすくなる
