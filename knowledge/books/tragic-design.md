# 悲劇的なデザイン / ジョナサン・シャリアート、シンシア・サヴァール・ソシエ（高崎拓哉 訳）

- 概要: デザインが人を傷つけてしまう 4 つの類型（命に関わる悲劇・怒りを生む・悲しませる・疎外する）を、実際の事例とともに検証した本。良かれと思った設計や見落としが、ユーザーに深刻な害を与えうることを示す。それを避けるための考え方や、つくり手の責任のあり方を論じる。原著は O'Reilly 刊の Tragic Design（2017 年）。
- 使いどころ: UI による人災、デザインは人を殺すことがあるみたいな話とかに。
