# コーディングを支える技術 ―成り立ちから学ぶプログラミング作法 / 西尾泰和

- 概要: プログラミング言語の文法や機能が「なぜ今の形になったか」を歴史的な成り立ちから解き明かす本。スコープ・型・例外処理・オブジェクト指向・並行処理といった概念を、複数言語を比較しながら「どんな問題を解決するために生まれたか」という視点で説明する。言語を横断して通用する考え方の土台を作ることを狙いとしている。
- 使いどころ: プログラミングの歴史について言及する時など
