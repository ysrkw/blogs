# 改訂新版 良いコード／悪いコードで学ぶ設計入門 / 仙塲大也

- 概要: 良いコードと悪いコードを対比しながら、保守しやすく成長し続けるコードの設計を学ぶ入門書。悪い構造（密結合・巨大なクラスなど）の認識から始まり、名前設計、クラス設計、不変・条件分岐の整理、リファクタリング、設計と開発プロセスの関係までを段階的に扱う。「ITエンジニア本大賞2023」技術書部門で大賞を受賞した初版の改訂新版。
- 使いどころ: AI が書くコードの設計品質を語る軸。Claude Code などが生成するコードの良し悪しを判断する記事の根拠にしたい。[[unit-testing-principles-practices-and-patterns]] と並べてテスト／設計の両輪で使える。
