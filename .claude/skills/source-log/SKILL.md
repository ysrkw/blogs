# source-log

動画・Web記事・論文など、書籍以外のオンライン資料を記事で再利用できる形にして `docs/sources/` へ記録する。

## 入力

- ユーザーが示した URL または資料名
- 種別: `video`、`web`、`paper` のいずれか

資料名だけで対象を一意に特定できなければ、候補を示してユーザーに確認する。

## 進め方

1. 元資料を確認する
   - URL があれば直接開く。資料名だけなら Web 検索で公式の掲載元を探す
   - 動画は公式チャンネル、Web記事は原掲載ページ、論文は出版社・DOI・arXivなどを優先する
   - タイトル、著者・発信者、掲載元、公開日、URLを取得する
   - 論文に DOI がある場合は記録する

2. 要点を下書きする
   - 記事で参照し直せる粒度を保ち、2〜4文にまとめる
   - 全文を確認できていない場合は推測で補わず、確認できた範囲を明記する
   - ユーザーの理解や受け取り方と混同しない

3. 使いどころを聞く
   - どの記事やテーマで、何の根拠・補足として使いたいかを1問で聞く
   - ユーザーの言葉をそのまま残す
   - 使用先が決まっていなければ「未定」としてよい

4. 保存する
   - スラッグを資料タイトルから `kebab-case` で提案し、ユーザーに確認する
   - `docs/sources/{slug}.md` を末尾のテンプレートで作る
   - `docs/sources.md` の一覧へ1行追加する

## テンプレート

```markdown
# {タイトル} / {著者・発信者}

- 種別: {video | web | paper}
- 要点: {2〜4文}
- 使いどころ: {ユーザーの言葉、または未定}
- 出典情報:
  - 著者・発信者: {名前}
  - タイトル: {タイトル}
  - 掲載元: {サイト・チャンネル・学会・雑誌など}
  - 公開日: {YYYY-MM-DD。不明なら不明}
  - URL: [{掲載元}]({URL})
  - DOI: {論文にある場合のみ}
- 記事で引いた対応: （未使用）
- 登場記事: （なし）
```

索引へ次の行を追加する。

```markdown
- [{短縮タイトル}](sources/{slug}.md) — {種別}。{1行の要点}。{使いどころメモあり・記事未使用／登場: {slug}（役割）}
```

## 重要原則

- 書籍は扱わない。`book-log` を使う
- 出典情報を AI の記憶で埋めない
- 要点と使いどころを分ける
- ページの転載や長い引用を記録しない
- 記事で使ったら「記事で引いた対応」と「登場記事」を更新する
